# Firehose Loaders for MSM8916

This directory stores Qualcomm Firehose programmer binaries (`.mbn` / `.elf`) used for Emergency Download (EDL / 9008) mode communication with Snapdragon 410 (MSM8916) devices.

## Expected Files
- `prog_emmc_firehose_8916.mbn`: Standard Qualcomm MSM8916 Firehose programmer.

## How to Obtain
1. From OpenStick or Firehose-Finder repository collections:
   - https://github.com/hoplik/Firehose-Finder
   - https://github.com/bkerler/Loaders
2. The flasher will auto-detect any loader placed in this folder or match device-specific recommendations.
